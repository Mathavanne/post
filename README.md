# POSTANIX — Posters × Ideas × Impact (Showcase Edition)

Official showcase website for **POSTANIX** displaying our wall poster designs across **Anime**, **Comics**, **God & Spiritual**, and **Cartoon** categories.

## Brand Color Palette
- **Electric Blue**: `#3B82F6`
- **Impact Gold**: `#FBBF24`
- **Midnight Dark**: `#0B1020`
- **Alabaster Off-White**: `#F8FAFC`

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
